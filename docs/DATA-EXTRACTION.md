# 🔓 مرجع: طرق سحب البيانات وتجاوز الدخول — وكيف تسدّها

بحث منظّم بكل الطرق العملية اللي ممكن مهاجم يسحب فيها بياناتك أو يتجاوز تسجيل الدخول،
مع: **كيف تشتغل → كيف تكشفها/تختبرها → هل الأداة تغطيها → كيف تسدّها**.
الهدف دفاعي: تعرف كل منفذ تسريب حتى تسدّه وتأمّن تطبيقك.

> كل التقنيات هنا تُطبَّق فقط على أنظمة أثبتّ ملكيتها عبر بوابة التحقق.

---

## القسم الأول: سحب البيانات (Data Extraction)

### 1. SQL Injection
أشهر وأخطر طريق لسحب قاعدة بيانات كاملة.

| النوع | كيف يشتغل | الكشف |
|------|-----------|-------|
| **Error-based** | حقن يكسر الاستعلام فيظهر خطأ يسرّب بنية/بيانات | حقن `'` ورصد توقيع خطأ SQL |
| **UNION-based** | `UNION SELECT` لسحب أعمدة من جداول أخرى | مطابقة عدد الأعمدة ثم سحب بيانات |
| **Boolean-based (blind)** | `AND 1=1` مقابل `AND 1=2` → فرق استجابة | مقارنة طول/محتوى الردّين |
| **Time-based (blind)** | `SLEEP(5)` → تأخير الرد يؤكّد الحقن | قياس زمن الاستجابة |
| **Second-order** | يُخزَّن الحقن ثم يُنفَّذ في سياق آخر | اختبار المدخلات المخزّنة لاحقاً |

**الأداة تغطي:** error-based + boolean-based + إثبات UNION (استخراج قيمة واحدة).
**الإصلاح:** استعلامات مُعاملة (parameterized/prepared) حصراً، ORM آمن، تحقّق من المدخلات،
وصلاحية أدنى لحساب قاعدة البيانات.

### 2. IDOR / Broken Object-Level Authorization
الوصول لبيانات غيرك بتغيير معرّف (`/user/123` → `/user/124`).
- **الكشف:** بدّل المعرّف الرقمي/الـ UUID وراقب إن رجع سجل غيرك.
- **الأداة تغطي:** تبديل المعرّف ومقارنة السجلات الحساسة.
- **الإصلاح:** تحقّق على مستوى الكائن — صاحب الجلسة يملك المورد المطلوب.

### 3. Broken Function-Level Authorization
نقاط إدارية (`/admin/*`, `/api/.../export`) مكشوفة بلا تحقق صلاحية.
- **الكشف:** استدعِ النقاط الحساسة بلا توكن/بدور عادي.
- **الأداة تغطي:** فحص نقاط `admin/config/backup/...` بلا مصادقة.
- **الإصلاح:** deny-by-default + تحقّق دور في كل نقطة على الخادم.

### 4. Mass Assignment / Excessive Data Exposure (APIs)
API يرجّع حقولاً أكثر من اللازم (كلمات سر، أدوار) أو يقبل حقولاً لا يجب (`role=admin`).
- **الكشف:** افحص ردود الـ API عن حقول حساسة، وجرّب إضافة حقول في الطلب.
- **الإصلاح:** حدّد الحقول المُخرَجة/المقبولة صراحةً (allow-list / serializers).

### 5. ملفات وأسرار مكشوفة
`.env`, `.git/config`, نسخ احتياطية, `/debug`, فهرسة مجلدات, تعليقات بالكود.
- **الأداة تغطي:** فحص `.env` و `.git/config` ونقاط debug/config.
- **الإصلاح:** امنعها من جذر الويب وأزل أسرارها، استخدم خزنة أسرار.

### 6. SSRF → سحب بيانات داخلية
إجبار الخادم يجلب موارد داخلية (ميتاداتا سحابية، خدمات محلية).
- **الكشف:** نقاط تجلب URL → وجّهها لموارد داخلية.
- **الإصلاح:** allow-list للوجهات، امنع العناوين الخاصة و`file://`.

### 7. Path Traversal / LFI
`?file=../../etc/passwd` لقراءة ملفات خارج المسموح.
- **الإصلاح:** `basename` + تأكيد المسار داخل مجلد مسموح + allow-list.

### 8. GraphQL / API over-fetching
`introspection` مكشوف، أو استعلامات متداخلة تسحب بيانات مرتبطة.
- **الإصلاح:** عطّل introspection بالإنتاج، حدّد العمق/التعقيد، تحقّق صلاحية لكل حقل.

## القسم الثاني: تجاوز تسجيل الدخول (Auth Bypass)

### 1. SQLi Auth Bypass
`' OR '1'='1'-- -` في حقل المستخدم يتجاوز التحقق.
- **الأداة تغطي:** حمولات تجاوز كلاسيكية ورصد نجاح الدخول.
- **الإصلاح:** استعلامات مُعاملة للمصادقة.

### 2. Default / Weak Credentials
`admin/admin`, حسابات افتراضية، كلمات سر ضعيفة.
- **الأداة تغطي:** قائمة صغيرة من البيانات الشائعة (بلا تخمين جماعي).
- **الإصلاح:** امنع الضعيف/الافتراضي، افرض سياسة قوية، MFA.

### 3. Missing Rate Limiting → Brute Force / Credential Stuffing
لا حدّ للمحاولات → تخمين كلمات السر.
- **الأداة تغطي:** رصد غياب الحظر بعد محاولات قليلة (بلا brute-force فعلي).
- **الإصلاح:** تحديد معدّل + قفل مؤقت + CAPTCHA + كشف credential stuffing.

### 4. JWT Weaknesses
- `alg:none` → توكن بلا توقيع.
- `HS256` بمفتاح ضعيف → تزوير.
- خلط RS256/HS256 (algorithm confusion).
- **الأداة تغطي:** كشف `alg:none` والتوقيع المتماثل.
- **الإصلاح:** ثبّت الخوارزمية، مفتاح قوي، تحقّق صارم من التوقيع والانتهاء.

### 5. Session Management Flaws
- كوكي بلا `HttpOnly`/`Secure`/`SameSite`.
- توكن جلسة متوقّع/غير عشوائي.
- Session fixation، عدم إبطال الجلسة عند الخروج.
- **الأداة تغطي:** فحص خصائص كوكي الجلسة.
- **الإصلاح:** توكنات عشوائية قوية، خصائص كوكي كاملة، تدوير/إبطال سليم.

### 6. OAuth / SSO Misconfig
- `redirect_uri` مفتوح، `state` مفقود (CSRF)، التحقق من `aud`/`iss` ناقص.
- **الإصلاح:** allow-list لـ redirect، تحقّق `state`، تحقّق كامل من الـ token claims.

### 7. Password Reset / Account Recovery
- رموز إعادة ضعيفة/متوقّعة، تسريب الرمز، تجاوز الخطوات.
- **الإصلاح:** رموز عشوائية قصيرة العمر، ربط بالحساب، تحديد معدّل.

### 8. 2FA/MFA Bypass
- تخطّي خطوة التحقق، إعادة استخدام الرمز، لا حدّ للمحاولات.
- **الإصلاح:** افرض الخطوة على الخادم، رمز لمرة واحدة، تحديد معدّل.
